# SpendWise Dashboard Shell

A clean, responsive financial dashboard layout built using modern CSS techniques (**CSS Grid** and **Flexbox**) as the foundational shell for the SpendWise capstone project.

## 🚀 Live Demo / Overview
This project serves as a static visual layout representing a modern financial tracking application. It features a sidebar navigation menu, a top header, and category tracking cards.

---

## 🛠️ Built With
* **HTML5**: Semantic markup for the dashboard structure.
* **CSS3**: Styling, layout management, and micro-interactions.
* **CSS Custom Properties (Variables)**: Used globally for a consistent and easily maintainable color palette (including a dark theme option).
* **CSS Grid**: Manages the macro layout (overall page structure and card grid).
* **Flexbox**: Manages micro-layouts (alignment inside the header, sidebar, and cards).
